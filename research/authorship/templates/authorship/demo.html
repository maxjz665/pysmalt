Методы атрибуции

Метод 1 — Профильный (Ежов)

Для каждого автора строится медианный синтаксический профиль (вектор 193 признаков, нормализованный пофолдово). Неизвестный текст сравнивается с профилями по Манхэттенскому расстоянию с блочными весами.

  • 193-мерный вектор признаков (8 блоков)
  • Fold-wise z-score нормализация — без утечки
  • Медианная агрегация профиля (робастна к выбросам)
  • Блочные веса: синтаксические конструкции × 1.3
  • Оценка: Leave-One-Out, macro-F1
Лучший F1: {{ best.profile_f1 }}%
Метод 2 — ML / SVM (Севрюков)

Обучается классификатор SVM с RBF-ядром на синтаксических признаках текстов. Гиперпараметры подбираются через GridSearchCV с вложенной кросс-валидацией (outer LOO, inner 3-fold Stratified KFold).

  • SVM (RBF) + StandardScaler в пайплайне
  • SelectKBest (ANOVA F-score) — отбор признаков
  • GridSearch по C, gamma, kernel, k признаков
  • Nested CV — без утечки при оценке качества
  • Feature importance — что наиболее дискриминативно
