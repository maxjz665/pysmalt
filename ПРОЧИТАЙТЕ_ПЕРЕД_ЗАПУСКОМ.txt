SMALT — Модуль определения авторства текста
============================================

БЫСТРЫЙ ЗАПУСК (smoke-режим, без dump)
---------------------------------------
1. Откройте папку pysmalt
2. Запустите: run_smoke_authorship.bat
   Скрипт создаст .venv, установит зависимости,
   загрузит smoke-корпус (3 автора x 4 текста),
   запустит worker и веб-сервер.
3. Откройте в браузере: http://127.0.0.1:8000/research/authorship/


ПОЛНЫЙ ЗАПУСК (реальные корпуса 5x8, 5x7, 7x6)
-------------------------------------------------
1. Положите файл smalt.sql.20260115.070144.gz
   рядом с manage.py (в эту же папку pysmalt)
   или на одну папку выше.
2. Запустите: run_full_authorship.bat
3. Откройте в браузере: http://127.0.0.1:8000/research/authorship/


LINUX / macOS
-------------
  bash run_smoke_authorship.sh     # smoke без dump
  bash run_full_authorship.sh      # полный запуск


WORKER (нужен для кнопок Profile / ML)
----------------------------------------
Скрипты запускают worker автоматически в отдельном окне.
Если нужно запустить вручную:
  Windows:  RUN_AUTHORSHIP_WORKER.bat
  Windows:  RUN_AUTHORSHIP_WORKER.ps1
  Linux:    bash smalt-authorship-worker.sh


ЧТО ДОСТУПНО В ИНТЕРФЕЙСЕ
---------------------------
- Profile и ML эксперименты по спискам текстов
- Очередь и статусы экспериментов (обновляются автоматически)
- Атрибуция произвольного текста (профильный метод)
- Атрибуция фрагментов текста (экспериментальный режим)
- Отчёты по корпусам


ВАЖНО
-----
* Первый запуск эксперимента по реальному корпусу может занять
  несколько минут: признаки извлекаются через Natasha/Razdel-пайплайн.
* Dump и папка .venv не входят в GitHub-репозиторий.
* Smoke-корпус встроен в проект и не требует dump.
